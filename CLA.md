# Contribuciones a MZTrain

MZTrain se distribuye bajo la licencia **MIT** (ver [`LICENSE`](LICENSE)). Las
contribuciones siguen el modelo estándar de los proyectos MIT: **inbound =
outbound**. No se exige cesión de copyright.

## Términos

1. **Licencia (inbound = outbound).** Al enviar una contribución (Pull Request,
   parche, documentación, test, benchmark, etc.), aceptas que se licencie bajo la
   **misma licencia MIT** del proyecto. Conservas el copyright de tu contribución;
   MIT permite que el proyecto y terceros la usen, modifiquen y redistribuyan
   conservando el aviso de copyright.

2. **Origen (DCO).** Declaras que tienes derecho a aportar la contribución (es tuya
   o tienes permiso para licenciarla bajo MIT). Lo certificas firmando tus commits
   con el *Developer Certificate of Origin*:

   ```bash
   git commit -s -m "feat: ..."
   ```

   que añade la línea `Signed-off-by: Nombre <email>` (ver https://developercertificate.org/).

3. **Sin garantía.** La contribución se aporta "tal cual", conforme a la cláusula de
   ausencia de garantía de la licencia MIT.

4. **Atribución.** Se te acreditará en el historial de commits y, cuando
   corresponda, en las notas de versión.

No necesitas firmar ningún documento aparte: abrir un Pull Request con tus commits
firmados (`-s`) implica la aceptación de estos términos. Ver también
[`CONTRIBUTING.md`](CONTRIBUTING.md).
